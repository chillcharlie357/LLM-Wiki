# 牛客提示词工程题单解析

来源：

- AI coding 题目：https://www.nowcoder.com/problem/aicoding/
- Prompt 提示词题目：https://www.nowcoder.com/exam/oj/ta?tpId=408
- Multica 来源任务：WOR-37 / WOR-38

## 原始整理摘要

牛客提示词工程题单（PROMPT1-PROMPT35）整体不是考普通聊天能力，而是考把自然语言稳定转换成指定 JSON 的能力：字段完整、枚举准确、规则优先级清楚、数值计算可复现、缺失值按题面处理、最后只输出 JSON。

通用 Prompt 骨架：

```text
你是严格的数据抽取/规则计算器。请只根据输入文本和下列规则输出 JSON，不要输出解释、Markdown 或多余字段。

处理步骤：
1. 先抽取原始信息，缺失字段按默认值处理。
2. 对枚举字段按题面映射，无法匹配时使用题面要求的 UNKNOWN / 空字符串 / false / null。
3. 对数值字段统一单位、保留位数、取整方式。
4. 多规则冲突时按题面优先级执行，并记录触发规则。
5. 输出必须严格匹配 JSON Schema，字段顺序、字段名、数组排序按要求执行。
```

最容易丢分的点：

- 没有声明“只输出 JSON”。
- 没有把缺失值默认值写死。
- 没有强调枚举大小写。
- 没有说明排序规则。
- 计算题没有写优先级、取整和保留小数。
- 复杂题没有要求先按步骤处理、最终只输出 JSON。

## 题型分组

- PROMPT1-PROMPT9：基础信息分类和结构化抽取，核心是字段映射、默认值、枚举规范。
- PROMPT10-PROMPT18：进阶抽取，加入日期偏移、脱敏、单位换算、优先级、分段累计、工具调用参数。
- PROMPT19-PROMPT35：知识库规则计算，核心是按条款执行、处理互斥/叠加/红线规则，并返回触发规则编号。

## 后续追问整理

题目应按“输入自然语言 -> 输出严格 JSON”的工程题来做。核心套路是：先把题目规则改写成可执行流程，再给模型一个固定输出 Schema。

通用思路：

1. 先定角色：不是聊天助手，而是严格 JSON 抽取器、规则计算器、审批判定器。
2. 再定边界：只能根据输入和题面规则，不补充常识，不输出解释。
3. 再定流程：抽取原始信息 -> 归一化 -> 按优先级执行规则 -> 计算字段 -> 校验 JSON。
4. 最后定格式：字段名、枚举值、默认值、排序、保留小数、取整方式必须写死。

通用结尾：

```text
最终只输出一个合法 JSON 对象，不要输出 Markdown、解释、推理过程或多余字段。无法判断的内容严格按题目默认值处理。
```
